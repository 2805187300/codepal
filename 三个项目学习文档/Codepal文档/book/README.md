## 使用建议

- **第一遍**：按顺序读第1-4章，建立 Agent 基础认知
- **第二遍**：按简历亮点对照章节精读，掌握面试话术
- **面试前**：重点复习第6、8、15、16章（高频考察点），通读第18章（攻略）
- **深挖**：每章末尾有"生产中可能遇到的问题"，面试追问时能体现工程深度
- 遇到不懂的概念直接对照 `src/` 下的源代码，代码是最权威的解释
